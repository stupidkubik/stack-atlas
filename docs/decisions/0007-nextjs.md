# 0007. Next.js для веб-приложения — S4, вариант A

Дата: 5 октября 2026. Статус: принято владельцем проекта.

## Контекст и варианты

Рассмотрены Next.js App Router, Astro с React и React Router Framework Mode. Sanity и Vercel уже приняты. Владелец выбрал стек на Next.js.

## Решение

Веб-приложение строим на Next.js App Router с React и TypeScript. Серверный HTML содержит основной контент и SEO; клиентские компоненты обслуживают интерактивный поиск, фильтры и выбор сравнения. Preview и серверные обработчики находятся в приложении. Публичный кеш и доступ к drafts разделены.

Предложенная организация — один репозиторий с web, Studio и CLI, npm. На дату этого ADR поддерживающие инструменты были рекомендациями; текущие defaults приняты в ADR 0013/05: Tailwind CSS, shadcn/ui по необходимости, Zod, GROQ/Portable Text, Vitest, Playwright, axe, Lighthouse CI и ESLint. Этот ADR фиксирует выбор фреймворка; не утверждает автоматически все параметры кеша, версии, хранилище снимков и scheduler.

## Последствия и проверка

Точные стабильные совместимые версии Next.js, React, Sanity и Node.js закрепляем в прототипе и lockfile. Проверяем серверный HTML, защищённый preview, публикацию/снятие/rename, webhook и обновление кеша. Хранение/расписание приняты в ADR 0010 и уточнены ADR 0013; URL — ADR 0008 и 08.
