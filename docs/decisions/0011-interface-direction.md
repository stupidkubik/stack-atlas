# 0011. Каталог с редакционными элементами — направление S8

> Уточнение [ADR 0014](0014-learning-project-simplifications.md): макеты и визуальная система выполняются задачей CW-16 до сборки публичного каркаса CW-08.

Дата: 5 октября 2026. Статус: направление принято владельцем; макеты и детальный дизайн отложены на отдельную работу через дизайнерский скилл.

## Контекст и варианты

Рассмотрены A — каталог для разработчика, B — редакционный гид, C — интерфейс с акцентом на данные. Владелец принял A с редакционными элементами B. Отдельную проработку S8 через дизайнерский скилл владелец выполнит позже; этим решением она не запускается.

## Решение

- Главная: короткое обещание продукта, вход в каталог, выбранные сравнения и объяснение AI-readiness.
- Каталог: заметный поиск и фильтры, информативные карточки с назначением, размещением, AI-сигналами и выбором для сравнения.
- Карточка CMS: сначала условия выбора/отказа, затем характеристики, интеграция, метрики и доказательства.
- Сравнение: контекст задачи, краткий вывод, таблица различий, подробные условия выбора и источники.
- Методология: объяснение сигналов и формулы с примерами.
- Визуальное направление: светлая основа, чёткая типографика, нейтральные цвета и один акцент. Статусы сопровождаются текстом; AI-балл — полнотой проверки и датой.
- Мобильное сравнение сохраняет понятную связь значений с продуктами; доступность и клавиатурный сценарий обязательны.

## Что ещё требуется

Макеты основных экранов, состояния loading/empty/error/stale, компоненты, точные цвета/типографика и адаптивное поведение прорабатываются отдельно до реализации UI. Принятие направления не означает готовность макетов.
