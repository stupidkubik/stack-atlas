# 0005. Сбалансированный стартовый набор CMS — S2, вариант A

Дата: 5 октября 2026. Статус: принято владельцем проекта.

## Контекст и варианты

Рассмотрены A — сбалансированный набор, B — акцент на облачных CMS, C — акцент на самостоятельном размещении. Владелец выбрал A в рамках [полного стартового ядра](0004-release-scope.md).

## Решение

Для прототипа берём Sanity, Contentful, Strapi, Payload и Directus. Storyblok и DatoCMS — кандидаты на расширение до семи карточек первого релиза после проверки источников; их включение не является обязательным условием выпуска пяти основных карточек.

Начальные направления проверки пакетов:

| Продукт | Что проверяем |
| --- | --- |
| Sanity | `@sanity/client`, официальный клиент Content Lake |
| Contentful | Delivery SDK; Management SDK учитывается отдельно |
| Strapi | Официальный JS/TS-клиент и соответствие версии CMS |
| Payload | Local API, REST SDK, серверный пакет и связь с monorepo |
| Directus | `@directus/sdk` |

Это направления исследования, не утверждённый mapping primaryPackageId и не подтверждение AI-сигналов. Пакет для метрик/типов выбирается после проверки назначения и принадлежности. SDK чтения и серверный пакет не считаются автоматически сопоставимыми. Сценарий без сопоставимого пакета отдельно проверяется в прототипе.

Редакционные пары стартового набора: Sanity ↔ Contentful, Strapi ↔ Payload, Strapi ↔ Directus. При включении Storyblok добавляем Sanity ↔ Storyblok. Критерии приняты в ADR 0006; контекст каждой пары редактор формулирует при подготовке материала. Актуальный scope — ADR 0013.

## Последствия и проверка

Для каждого продукта сохраняем официальные источники, package/repository mapping или объяснение отсутствия сопоставимого пакета. Проверяем scoped SDK, monorepo, повторный импорт и честное отображение неприменимых метрик. Наличие в наборе не означает наличие официального MCP или полный AI-балл.
