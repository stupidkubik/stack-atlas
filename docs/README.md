## Приоритет решений

ADR 0001–0012 сохраняются как история решений; в них отмечены заменённые пункты. При конфликте применяем ADR 0013 и актуальные 02–12. Нельзя использовать прежний перенос аналитики или расширенную систему доставки как действующее требование. Новая развилка оформляется следующим ADR, а соответствующие спецификации обновляются вместе.

## Готовность к старту

Исполнимый backlog ядра — [полный план разработки](14-core-development-plan.md): пять детальных разделов, зависимости, прототип, критерии готовности задач и контроль Q01–Q19. План переводит контракты в работу; он не заменяет их и не является отчётом реализации. Начало — FP-01, затем общая конфигурация/SQL и три интеграционных потока.

Рабочая инфраструктура подготовлена: [статусы и журнал](work/README.md), [локальные evidence artifacts](../artifacts/README.md), root Git/README/AGENTS. Все 43 реализационные задачи пока planned; команды рабочего журнала доступны до npm-приложения.

Продуктовых/архитектурных вопросов, требующих отдельного согласования до кода, нет. Провайдеры, scope и смысл конверсии определены. Настройка аккаунтов, lockfile, API fixtures, дизайн макетов и сквозной прототип — реализационные задачи. Проверки тарифов/доступов могут выявить фактическую проблему; она исправляется до запуска, не скрывается документацией.

Отчёт согласованности — [13](13-documentation-review.md). Релизные gates сохраняются: Q01–Q19 и runbook должны быть выполнены. Root README уже описывает подготовку проекта; команды и функции приложения будут добавляться только после проверки реализации.
