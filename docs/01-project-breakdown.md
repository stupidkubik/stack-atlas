# PkgCompass: разбор и пересмотр концепции

Дата: 5 октября 2026. Актуализировано по [ADR 0013](decisions/0013-marketing-v1-and-simple-pipeline.md). Исходная [концепция](PkgCompass%20—%20концепция%20пет-проекта.md) сохранена как исторический замысел, текущий scope задаёт [02](02-product-and-scope.md).

## 1. Две цели

Пользовательская: помочь выбрать CMS для JS/TS-сайта по задаче, ограничениям и первоисточникам. Портфолио: показать навыки Frontend / Web Engineer (Marketing & Digital Experience), дополнив CMS/SEO реальной формой→CRM и измерением с согласием. Полный путь данных полезен, но не заменяет маркетинговые сценарии.

## 2. Почему прежний v1 пересмотрен

ADR 0004 переносил форму/consent/аналитику в следующую итерацию. ADR 0010/0012 и спецификации добавили ledger, receipts, pointers, попытки/hash-конфликты, reconciliation и переход окружений. Это рациональные механизмы для более строгих гарантий, но избыточный обязательный объём для маленького портфолио-каталога. Отложенные навыки были важнее для исходной цели.

При этом первоначальные 3–5 дней не были подтверждены: концепция включала 60–100 карточек, три языка, CRM/почту, A/B и агенты. Нельзя приписать весь рост оценки backend или обещать пятидневный релиз после упрощения. Новая оценка — гипотеза [05 §7](05-architecture.md#7-оценка-реализации), пересчитывается по прототипу.

## 3. Что сохраняем и сокращаем

| Сохраняем | Ограничиваем |
| --- | --- |
| 5–8 CMS, 3–5 редакционных сравнений | Не наращиваем каталог ради programmatic SEO |
| CMS, preview, публикация, SEO, доступность/performance | Без универсального builder и микросервисов |
| PostgreSQL + Actions + стабильные ID | Один collector writer, повторный сбор, snapshots/read queries |
| AI-сигналы с evidence и честной формулой | Manual review достаточен, детекторы позже |
| Обработка partial errors и backup | Без общего движка resume/reconciliation |
| Consent, события и одна CRM-форма | Без newsletter/DOI/email automation/A/B в v1 |

## 4. Демонстрация проекта

Редактор публикует comparison в CMS → SSR/SEO страница обновляется → посетитель изучает вывод/источники → открывает Request a CMS shortlist → заявка сохранена в Brevo → consenting funnel показывает lead_accepted. Без analytics consent форма работает. Источники/AI-сигналы имеют даты, ошибка не становится нулём.

Кейс показывает именно эти результаты. Локализация и A/B остаются незакрытыми до следующих работающих итераций; /en/ и поле locale не объявляются поддержкой нескольких языков. Метрики SDK не равны пользователям CMS, AI score не доказывает эффективность агента, analytics counts не равны всем CRM-заявкам.

## 5. Старт

Первый прототип включает CMS/DB/CRM/analytics вертикальный путь на небольшом seed, затем контент/UI/приёмка. Решения перед стартом — [00](00-start-decisions.md), рабочие контракты — [README](README.md), результат цельной сверки — [13](13-documentation-review.md). Код и реальные интеграции ещё не реализованы.
